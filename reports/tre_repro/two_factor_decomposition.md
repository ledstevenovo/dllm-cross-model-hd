# 两个因素的效应量：上下文 vs 预算

日期：2026-10-23 20:35。基于 9 个 TRE 格子。

## 可用的对照

| 模型 | 数据集 | prompt | 预算 | AUROC |
|---|---|---|---|---:|
| LLaDA | HotpotQA | 裸 | 128 | **0.838** |
| LLaDA | HotpotQA | 裸 | 64 | 0.804 |
| LLaDA | HotpotQA | 含上下文 | 128 | 0.745 |
| LLaDA | TriviaQA | 裸 | 128 | 0.783 |
| LLaDA | TriviaQA | 裸 | 64 | 0.702 |
| Dream | HotpotQA | 裸 | 128 | 0.822 |
| Dream | HotpotQA | 含上下文 | 128 | 0.719 |
| Dream | TriviaQA | 裸 | 128 | 0.795 |

（HotpotQA 含上下文的 L64 未跑；其余因素已控制。）

## 效应量

### 主要因素：prompt 是否含上下文

| 模型 | 裸 → 含上下文 | 效应 |
|---|---|---:|
| LLaDA / HotpotQA | 0.838 → 0.745 | **−0.093** |
| Dream / HotpotQA | 0.822 → 0.719 | **−0.104** |
| **平均** | | **−0.099** |

两模型一致，**这是本组实验最强的单一效应**。

### 次要因素：生成预算 128 → 64

| 模型 | 数据集 | 128 → 64 | 效应 |
|---|---|---|---:|
| LLaDA / HotpotQA（裸） | 0.838 → 0.804 | −0.034 |
| LLaDA / TriviaQA（裸） | 0.783 → 0.702 | −0.081 |
| **平均** | | **−0.058** |

预算效应在数据集间不一致（−0.034 vs −0.081），且**方向都是变差**。

### 数据集：TriviaQA vs HotpotQA（都闭卷）

| 模型 | TriviaQA | HotpotQA | 差 |
|---|---:|---:|---:|
| LLaDA | 0.783 | 0.838 | **+0.055** |
| Dream | 0.795 | 0.822 | **+0.027** |

**HotpotQA 反而比 TriviaQA 高 0.03–0.06**——多跳本身不影响 TRE，甚至更容易
（因为正类率 85% vs 63%，且这些题离了上下文多半答不出，熵信号更清晰）。

## 排序：哪个因素最重要

| 因素 | 效应量（AUROC） | 相对重要性 |
|---|---:|---:|
| **prompt 含上下文** | **−0.099** | **1.0** |
| 生成预算减半 | −0.058 | 0.59 |
| 换模型（**精度匹配**） | **0.000**（BF16 下 0.822418 vs 0.822365） | **0** |
| 换精度（FP16→BF16） | −0.0155 | 0.16 |
| 换数据集（TriviaQA→HotpotQA） | **+0.041**（变好） | — |
| 换 judge（同批轨迹） | 0.063（LLaDA HotpotQA） | 0.64 |

## 为什么预算效应在不同数据集上差别这么大

答案在**回答长度相对预算的位置**：

| Run | 中位长度 | 撞上限条数 | 终止方式 |
|---|---:|---:|---|
| Dream / TriviaQA L128 | **3** | 0 | eos ×800 |
| Dream / TriviaQA L64 | **2** | 2 | eos ×800 |
| LLaDA / HotpotQA 裸 L128 | 12 | 7 | eot 756 / eos 44 |
| LLaDA / HotpotQA 裸 L64 | 18 | **180（22.5%）** | eot ×800 |

- **TriviaQA 上模型 2–3 token 就答完**，预算 64 还是 128 都碰不到边界 → 预算效应应接近 0；
- **HotpotQA 裸问题上答案更长**（LLaDA 中位 12→18），64 的预算开始咬住 → 22.5% 被截断。

所以**预算效应不是常数，而是"预算是否切在答案分布内部"的函数**。
这解释了 −0.034（HotpotQA）与 −0.081（TriviaQA）的不一致：
TriviaQA 那一格虽然没撞上限，但 block 变小改变了生成动力学（L64 全部 EOT 结束、L128 有 44 条 EOS），
损失来自动力学而非截断。

## 结论

1. **prompt 是否含上下文是最重要的协议变量**（0.099），大于换 judge（0.063）和换预算（0.058）；
2. **换模型没有影响**（精度匹配后 **0.000**）：BF16 对照实验给出
   LLaDA 0.822418 vs Dream 0.822365（差 0.00005）。此前的 0.016 差异**全部来自精度**
   （FP16→BF16 的效应为 −0.0155）。详见 `precision_control_result.md`；
3. **换数据集方向相反**（HotpotQA 更好）——所以"多跳难"不是 TRE 的问题；
4. 报告 TRE 数字时，**prompt 类型必须与数值同时给出**，否则跨研究不可比。

## 对复现的意义

原文 Table 1 的六个格子如果包含 HotpotQA，其配置必然影响结果约 0.1。
我们不知道原文是否含上下文，这解释了为什么 HotpotQA 那两格在两种设定下相差 11 pp。
**这也是复制研究必须报告协议细节的最具体理由。**
