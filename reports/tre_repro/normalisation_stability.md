# 归一化分数的稳定性检验

日期：2026-10-24 06:15。回答一个合理的质疑：`tre_length_normalized` 除以有效长度，
在很短的答案（1–3 token）上会不会变得不稳定、甚至产生无穷大？

## 数值稳定性

| Run | n | 长度 ≤3 的占比 | `inf` 或 `nan` 数 |
|---|---:|---:|---:|
| LLaDA / TriviaQA L128 | 795 | 31.4% | **0** |
| Dream / TriviaQA L128 | 789 | **55.9%** | **0** |
| Dream / HotpotQA 裸 | 790 | 51.6% | **0** |

代码用 `safe_length = max(length, 1)` 保护，所以长度 1 也不会出问题。**全部 run 无 `inf`/`nan`。**

## 但"短答案占多数"意味着什么

Dream 的 TriviaQA 回答有 **55.9%** 只有 1–3 个 token。所以 Dream 的归一化分数
**主要由短答案决定**。这是好事也是坏事：

- **好事**：短答案的归一化更精确（分母小，但分子也同样小，比值稳定）；
- **坏事**：长答案的样本少，其归一化估计更嘈杂。

## 分层检验：两层的方向一致

| Run | 短答案（≤3）归一化 | 长答案（>3）归一化 | 短答案原始 | 长答案原始 |
|---|---:|---:|---:|---:|
| LLaDA / TriviaQA | **0.878** | 0.830 | 0.825 | 0.773 |
| Dream / TriviaQA | **0.906** | 0.849 | 0.814 | 0.760 |
| Dream / HotpotQA 裸 | **0.889** | 0.826 | 0.846 | 0.806 |

**三点结论**：

1. **归一化在两层的方向一致**（短答案更好、长答案稍差），没有出现"某层崩掉"；
2. **归一化在两层的数值都高于原始分**（0.878>0.825、0.830>0.773 等），
   说明它**不是靠牺牲一层来提升整体**；
3. 短答案层分数更高，这与"答案短 = 模型果断 = 熵信号清晰"一致。

## 这消除了一个替代解释

如果归一化只是"在短答案上碰巧更好"，那么它应该在长答案上明显更差。实测长答案层
也提升了（0.830 vs 0.773），所以**归一化是在两层都提取了更纯的信号**，不是抽样巧合。

## 剩余限制

- 每层内部的答案长度仍有很大差异（比如"长答案"从 4 到 126）；
- 未做"长度分箱后的逐箱 AUROC"——若某几个箱特别差，会被层平均掩盖；
- 归一化的分子是 `tre_effective`（有效区域内的加权和），所以它测的是
  **每 token 的平均熵贡献**，这个量与"答案有多果断"直接对应，符合直觉。

## 对论文的影响

应把这条检验写进限制与稳健性部分：**归一化分数经两层检验稳定，且在两层都优于原始分**。
它支持"用归一化版本报告跨条件比较"这一方法论建议。
