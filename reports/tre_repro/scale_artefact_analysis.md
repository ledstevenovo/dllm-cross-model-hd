# 归一化后的重算：原始 TRE 的预算效应大部分是尺度假象

日期：2026-10-24 03:25。全部从 `scores.csv` 重算，同 judge（LongCat）。

## 核心对照

| 对比 | 原始 `tre` | `tre_length_normalized` |
|---|---|---|
| **LLaDA TQ：L64 → L128 → L256** | 0.735 → 0.793 → **0.702** | **0.775 → 0.843 → 0.838** |
| Dream TQ：L128 → L64 | 0.797 → 0.899（+0.102） | 0.848 → 0.901（+0.053） |
| Dream HP 闭卷：L128 → L64 | 0.822 → 0.851（+0.028） | 0.778 → 0.793（+0.015） |
| Dream HP 开卷：L128 → L64 | 0.719 → 0.766（+0.048） | 0.741 → 0.779（+0.038） |

## 三个结论

### 1. LLaDA 的"倒 U"是尺度假象，实际是平台

| 预算 | 原始 | 归一化 |
|---|---:|---:|
| L64 | 0.735 | 0.775 |
| L128 | 0.793 | **0.843** |
| L256 | 0.702 | **0.838** |

归一化后 L128 与 L256 **几乎相同**（0.843 vs 0.838，差 0.005），只有 L64 略低（0.775）。
所以"块长太大反而变差"**不成立**；真实情况是**128 与 256 等价，64 略差**。

### 2. Dream 的预算收益真实但只有一半

原始 +0.102 中有约一半来自尺度；归一化后是 **+0.05**。
仍然为正，方向不变，但**效应量减半**。

### 3. 原始 TRE 不可跨预算比较

TRE 中位数：L64 = 9.6、L128 = 20.0、L256 = 39.6（同样约 12 token 的答案）。
块越大，每个位置聚合的熵越多，求和越大。**同一方法在不同预算下的原始分数不是同一个量。**

## 对整篇论文的影响

| 结论 | 状态 |
|---|---|
| "预算减半使 AUROC 下降 8.2 pp" | ❌ 撤回（原始分数）；归一化后 L64 比 L128 低 **0.068**（0.775 vs 0.843），方向相同但幅度不同 |
| "缩短块长提高检测（+0.04~+0.10）" | ⚠️ 减半为 **+0.015~+0.053** |
| "L256 预测失败" | ⚠️ 部分改写：预测本身没错（截断不是主因），但我误把尺度效应当成"大块更差" |
| "TRE 在四格与原文差 2.6 pp" | ✅ 不受影响——原文对照都是同预算（128），尺度相同 |

## 最关键的实操结论

**跨预算比较必须用 `tre_length_normalized`；跨模型/跨数据集比较可以用原始 `tre`**
（因为预算相同、尺度相同）。

这也解释了原文表 1 的一个特点：它的 128 与 64 两列若用原始 TRE，差异里必然含尺度成分；
除非原文用的是归一化版本，或两列的实际生成长度相同。

三次错误都源于同一个模式：**用一个未归一化的量做跨条件比较**。
TRE 是求和，任何改变"位置数"的操作（块长、生成长度、prompt 中的上下文长度）
都会改变它的尺度。这是方法本身的属性，不是实验缺陷，但必须在报告里显式处理。
