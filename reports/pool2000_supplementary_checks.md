# 扩池后三项检验：全部推翻 pilot200 的异常

日期：2026-10-23 03:00。产物：`reports/pool2000_permutation.json`、`reports/pool2000_alignment_diagnostic.json`、`results/pool2000/strata/transfer_matrix.csv`。

## 1. 簇级置换检验（10000 次，16 格）

| 结果 | pilot200 | **2000 题** |
|---|---|---|
| 显著格数（p < 0.01） | 12 / 16 | **16 / 16** |
| 异常格 `rel+LR Dream→LLaDA` | p = **0.53** | p = **1e-4**（下界） |
| `ent+MLP Dream→LLaDA` | p = 0.19 | p = **1e-4** |
| 零分布 p95 | 0.62–0.66 | **0.547–0.549** |

零分布 p95 从 0.65 降到 0.548，正是样本量增大的直接结果（n=48 时随机标签能凑到 0.65，n=450 时只能到 0.55）。

**16 格全部 p ≤ 4e-4**，包括此前与随机无异的两格。这不是"某几格变显著"，而是**整个矩阵都建立了信号**。

## 2. 尺度对齐诊断（8 格）

| 格 | 原尺度 | 目标域标准化 | 分位对齐 |
|---|---:|---:|---:|
| `rel+LR Dream→LLaDA` | **0.752** | 0.751 | 0.764 |
| `rel+MLP Dream→LLaDA` | 0.600 | 0.601 | 0.726 |
| `ent+LR Dream→LLaDA` | 0.671 | 0.667 | 0.763 |
| `ent+MLP Dream→LLaDA` | 0.680 | 0.537 | 0.753 |
| `rel+LR LLaDA→Dream` | 0.865 | 0.865 | 0.842 |
| `rel+MLP LLaDA→Dream` | 0.739 | 0.813 | 0.600 |
| `ent+LR LLaDA→Dream` | 0.854 | 0.854 | 0.837 |
| `ent+MLP LLaDA→Dream` | 0.839 | 0.828 | 0.710 |

**关键读法**：`rel+LR Dream→LLaDA` 从 0.752 到分位对齐 0.764——**几乎没有变化**。pilot200 上"对齐把 0.494 修复到 0.850"是整个机制叙事的支柱，现在这个修复不存在了，因为**没有问题需要修复**。

顺带一个反向发现：分位对齐在**多个格上反而变差**（`rel+MLP LLaDA→Dream` 0.739→0.600、`ent+MLP LLaDA→Dream` 0.839→0.710）。原因是分位映射用目标域 train 的分位重排目标域 test，等于用目标域信息做了变换；样本变大后，它引入的扭曲超过了它修正的漂移。所以"分位对齐能修复跨模型迁移"这个说法在新数据上不成立，且方向上不稳健。

## 3. 跨数据集轴（32 格）

| 项 | pilot200 | 2000 题 |
|---|---|---|
| 最低格 | `ent+MLP LLaDA→triviaqa` **0.471** | `rel+MLP LLaDA→hotpotqa` **0.663** |
| 最高格 | 0.927 | 0.886 |
| 低于 0.5 的格数 | 2 | **0** |
| hotpotqa test 负例数 | 3–4 | **210–238（可用样本）** |

pilot200 上"MLP 换数据集就崩到 0.47"的观察消失。hotpotqa 层从 3–4 个负例变成 200+ 个，此前"异常由小层驱动"的诊断因此**不再适用**——不是诊断错了，是层本身变了。

## 统一结论

三项检验各自独立，却指向同一个事实：

> pilot200 的异常不是机制，是 n=48（以及 hotpotqa 层 n=4 负例）的抽样尾部。扩池后，**没有任何一格表现出失效**。

这与 `reports/pool2000_verdict.md` 的判据失败、`reports/pool2000_learning_curve.md` 的分位数分析互相印证。
